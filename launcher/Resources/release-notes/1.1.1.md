# Mactician Release Notes — 1.1.1

- Adds a versioned, one-time activation snapshot after your Extended
  Diagnostics choice is known.
- The snapshot records only the explicit granted/denied state, consent and
  snapshot versions, and launcher version/build. It contains no game-session
  diagnostics or stable installation identifier.
- Retries reuse the same event ID until the telemetry backend acknowledges the
  snapshot, without affecting normal gameplay or Extended Diagnostics consent.
