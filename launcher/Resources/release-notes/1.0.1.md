# Mactician Release Notes — 1.0.1

- Adds a dedicated **Update game** action for TFT.
- Downloads signed game manifests and split APK files from `sergeinaumov.dev`.
- Verifies the feed signature, HTTPS origin, file sizes, and SHA-256 hashes before installation.
- Installs game updates without uninstalling TFT, preserving Riot sign-in and local game data.
- Keeps a verified bundled APK fallback for first installation when the update service is unavailable.
