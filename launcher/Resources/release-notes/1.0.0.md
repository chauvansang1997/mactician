# Mactician Release Notes — 1.0.0

Mactician 1.0.0 is the initial public version.

- Native SwiftUI experience for preparing and playing TFT on Apple Silicon.
- Verified Android Emulator, ANGLE, Vulkan, and MoltenVK runtime components.
- Built-in installation, Play, Repair, Reset, settings, hotkeys, and secure updates.
- Runtime data stored in `~/Library/Application Support/Mactician`.
