# Mactician Release Notes — 1.0.8

- Adds best-effort support for Apple Silicon Macs with 8 GB of unified memory.
- Uses a reduced 4 GB Android guest on 8 GB Macs during installation and play.
- Keeps the existing 6 GB default on Macs with 16 GB of memory or more.
