# Mactician Release Notes — 1.0.4

- Restores four asynchronous OpenGL shader compiler services after the latest
  TFT update disabled them in its inherited Android device profile.
- Moves first-use PSO compilation away from the gameplay render path to reduce
  recurring combat freezes and improve frame pacing while the shader cache warms.
- Keeps the Performance and High detail profiles protected against the same
  upstream profile regression.
